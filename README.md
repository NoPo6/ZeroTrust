## In order to install and set up Netbird one need:
* curl -fsSL https://github.com/netbirdio/netbird/releases/latest/download/getting-started.sh | bash -s -- --domain use-ip

## For Topaz one need:
1. brew install --cask aserto-dev/tap/topaz
2. topaz certs trust
3. topaz install
4. topaz templates install todo
